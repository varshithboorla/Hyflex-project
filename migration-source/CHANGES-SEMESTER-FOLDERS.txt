NEW RULES
  * Every academic year gets two folders AUTOMATICALLY (database trigger):
        Odd  (e.g. Jun-Dec) -> semesters 1, 3, 5, 7
        Even (e.g. Jan-May) -> semesters 2, 4, 6, 8
    No manual folder creation. "Sync folders" button = safety net.
  * A folder only takes courses of its own type (enforced in the UI AND the database).
  * Adding a course = course name + BATCH(es) + branches.
      - regulation comes from the batch
      - semester = batch + folder  (2024 batch in the 2026-27 Odd folder = Sem 5)
      - tick several batches to create the course for all of them in one go
      - the course name list reuses existing subjects (no duplicates)
  * course_offerings now has folder_id and batch_id (folders moved from courses to offerings).
